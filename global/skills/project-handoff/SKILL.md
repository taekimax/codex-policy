# Project Handoff

Inspect the current request, applicable project instructions, existing plan/status, exact Git root, branch, and dirty state. Check runtime or installed state only when it affects the next outcome; distinguish current verification from historical reports.

Use the global handoff guidance and `$CODEX_HOME/templates/session-handoff.txt` (default home: `~/.codex`) instead of maintaining a second format here. Omit irrelevant fields. Include user availability only when it changes the next step. Carry the global model-family delegation policy into an implementation handoff without pinning versions.

Return one self-contained copy-paste block. Refer to the existing plan for implementation detail, keep private source contents and secrets out, and preserve the current authority limits. Preparing a handoff does not execute the next action or create a new task.
